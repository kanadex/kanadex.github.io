## 它做了什么

可跟随鼠标改变角度的台灯、有趣的窗口管理以及前端实现的终端页面。

## 运行

```bash
pnpm install
pnpm dev      # http://localhost:7777
pnpm build    # 产物在 dist/
```

需要 Node ≥ 20.10 与 pnpm
